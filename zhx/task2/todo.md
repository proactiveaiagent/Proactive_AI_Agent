# 任务 2 · 7 层记忆模型体系（09-12 会议后重构版）

> 任务 2：终身用户建模与画像精化（Lifelong user modeling and personas refinement）
>
> **09-12 会议重定义**：工作范围从「layer6 用户画像优化」扩大为**整个 7 层记忆模型的优化**。
> 核心交付：记忆模型的基础架构 + **增删改查（CRUD）机制** + 数据归类压缩流程 + 一套完整体系与说明书。
> 范围边界：09-12 初始范围只覆盖记忆模型；09-29 验收会议将多模态事件证据，以及**以记忆为依据**的语义检索和行动建议纳入 Task2。工作仍限于记忆模型和其决策接口，不扩成通用 LLM 功能。

## 一、验收标准（月末验收 · EgoLife 测试集）

测试集需**自行收集并处理 EgoLife 数据集**，用它验证不同数据量下的处理能力与遗忘机制合理性。

| 指标 | 目标 | 说明 |
|---|---|---|
| 存储容量 | ≤ 100GB | 通过压缩与合并控制；会议另定硬上限 200GB，需评估合理恒定值 |
| 提取速度 | ≤ 1s | 重点是**数据提取/检索速度**不能太久；会议口径放宽为 1~3s |
| 准确率 | ≥ 95% | 基础操作的归类准确性，不得出现明显类别混淆错误 |

⚠️ 评测口径补充：记忆检索 P@5=97.5% 不能证明本表“基础操作归类准确性 ≥95%”。现用视频证据与转写进行独立 AI 语义评审；AI 结果不称为人工金标准，样本不足时不外推至全量。

**验收场景（09-23 会议新增）：**

1. **短期记忆场景**：使用不连续视频片段测试集，验证 Layer1~7 的完整 CRUD 流程
   - 验证白天实时写入、检索、更新、删除链路
   - 验证场景结束后短期记忆的自动清理

2. **长期记忆场景**：使用完整一天测试集，验证记忆流转与夜间整理
   - 验证一天过程中的记忆累积与层间流转
   - 验证夜间离线整理：合并、归类、压缩、画像更新
   - 重点验证长期记忆如何从当日记忆中提炼并更新用户画像

3. **可视化验收**：搭建可视化网站
   - 直观展示各层记忆状态
   - 支持时间轴回放，展示记忆在一天中的演化过程
   - 展示 CRUD 操作对记忆的影响

## 二、范围澄清（09-12 / 09-23 会议）

1. 7 层记忆模型**均围绕用户画像**展开，本次重点 = 构建基础架构 + 实现增删改查流程，而非仅 layer6 局部优化。
2. 属性统一结构：所有属性统一带**置信度 / 时间戳 / 最后使用时间**等字段（已落地的 AttrValue）。
3. 遗忘机制**按属性类型差异化**（三类，09-23 会议确认）：
   - **身份类**（如性别/姓名）：长久不衰减的记忆；
   - **经历类**（如上学阶段）：按缓慢衰减机制处理；
   - **时效类**（如过期优惠券）：到达设定时间直接遗忘。
   - 目标：Agent 能根据属性类型**自主判断**合理的衰减策略。
4. 文档规范：工作文档需**摒弃日报周报式概括**，改成「说明书 + 论文」形式，具体记录设计原理、代码位置、修改说明（见 `report.md`）。
5. 代码规范：之后的代码与产出**直接放主目录对应位置**（如 `scripts/memory/`），不再放 `zhx/` 下。
6. **双阶段处理流程**（09-23 会议新增）：
   - **短期记忆（闪存）**：白天实时快速存储与提取，为 Agent 提供上下文，场景结束后即可删除；
   - **长期记忆（整理）**：夜间对全天数据做总结、关联分析并更新用户画像，执行压缩合并控制摄入总量。
7. **非英文文本处理**（09-23 会议新增）：记忆存储时调用 LLM 翻译为英文统一存储，后台离线执行，不影响检索速度。
8. **多模态数据写入链路**（09-23 会议确认）：新的一天接收视频处理后，基于时间和计数器生成唯一 ID 写入 Layer1 临时记忆，随后根据地点和活动一致性分流至 Layer2（同场景）/ Layer3（当日记忆，最多 1000 条）/ Layer7（永久记忆）。
