## 三、分阶段任务

### 第一阶段（飞书内部汇报前必须完成，优先级最高）

**T1 图像裁剪优化（@张鸿兴）**
- 目标：人物/物品裁剪更准，尤其"姥姥"这类人物。
- 做法：引入 YOLO 等轻量检测模型替代/补充 OpenCV 小模型（ming 已认可，避免大模型开销）；人脸模糊场景可评估人脸识别方案。
- 验收：自定义测试集 35 段中，人物 crop 能框到对应人物（而非整帧/错位）；物品只裁个性化物品。

**T2 记忆信息统一翻译成英文（@张鸿兴）**
- 目标：特征、外观、关系、背景等记忆字段统一为英文。
- 做法：在写入路径统一过 `translator.py`（或等价翻译层），保证缓存与记忆库一致；保留中文原话作为证据（evidence 字段不翻译）。
- 验收：抽样 35 段，结构化字段无中文残留（evidence 原文除外）。

**T3 夜间归纳跑通 + 可视化缓存 Bug（@张鸿兴）**
- 目标：夜间归纳（短期→摘要→长期画像）端到端跑通；修复网页缓存 Bug。
- 做法：先确认 LLM 端点可用（`systemd-run --user` 起 `/consolidate` 服务）；再跑夜间归纳；复现并修可视化缓存 Bug（区分已修的 KPI/按钮问题与未修的 resume/快照问题）。
- 验收：自定义测试集跑完一天后，夜间归纳产出摘要+画像更新，页面正确显示。

**T4 自定义测试集达到飞书汇报要求（@张鸿兴，最优先）**
- 目标：把飞书「AR Agent测试数据」文档里的要求逐条满足并演示。
- 重点（文档视频1/视频2，过年/姥姥场景）：
  1. 识别"姥姥"身份并存入记忆（语音推断）；
  2. 关联 **过年(时间)+姥姥(人物)+姥姥家(地点)+拜年(事件)**；
  3. 跨片段复用：视频2 能从 memory 提取出"人物是姥姥/地点是姥姥家/要拜年"（对应 P8，需跨片段身份关联）；
  4. 输出姥姥在画面中的位置（bbox）给下游。
- 验收：用 v9 重刷 35 段 + 我的离线回放驱动（`scripts/memory/replay_custom_memory_offline.py`）产出前后对比表，逐条对照飞书文档打勾。

### 第二阶段（基础功能完善后）

**T5 记忆主动压缩与分层（参考 EgoMemo）**
- 目标：对海量记忆做主动分类、提取、压缩，而非被动相似度检索。
- 参考：EgoMemo 的流式记忆构建（多尺度时间摘要 + 语义知识图谱 + 视觉嵌入档案）+ 流式检索增强推理（显式干预决策）。
- 做法：基于语义理解动态调整记忆权重、按时间线和重要性排序、剔除冗余细节（ming："像人脑遗忘曲线"）。
- 验收：给定一天数据，压缩后体积/条目数可控，检索 P@5 不降。

**T6 深层用户画像构建**
- 目标：构建可外推的深层画像（病史、习惯、关系网等底层特征），使无直接相似记忆时仍能支撑下游推断。
- 边界：记忆模型负责画像的**存储与检索**；触发急救/提醒是下游。
- 验收：画像字段结构化、带置信度与证据；可被检索接口命中。

**T7 大数据集压力测试**
- 目标：验证海量数据下的记忆压缩与提取效果。
- 数据集：**名称待确认**——会议出现 EgoSurf / Ego4D / EgoServe 多个说法，需向 ming 确认用哪个（建议 Ego4D 做压力测试，EgoServe 做检索评测，二者用途不同）。
- 验收：在大数据集上跑通压缩+提取，给出容量/速度/准确率指标。

## 四、边界与红线（不要越界）

1. 记忆模型**不做**医疗诊断、需求推断、行动建议、主动提醒（下游职责）。
2. 人物外观只记可见特征；**年龄不从长相推测**，只读画面文字；身份/关系必须有证据，证据不足标低置信并记录依据。
3. 不把零散事实和口述原文当独立主记忆卡片；口述内容用于丰富人物/关系/事件/场景，保留来源证据。
4. 通用物品不裁剪；个人物品必须绑定 owner。
5. 最多占用 **2 张 GPU**（本轮临时 4 张已获授权，跑完即释放）；禁止 GPU reset；长任务用 `systemd-run --user`。
6. 不提交 Git，除非另行要求。
