# M3-Agent 记忆机制调研

参考：https://github.com/ByteDance-Seed/m3-agent（ICLR 2026）

## 核心架构

- **双进程**：Memorization（记忆构建）与 Control（指令执行）
- **记忆类型**：Episodic（情景记忆）+ Semantic（语义记忆）
- **存储形式**：实体为中心的多模态图（Entity-centric Multimodal Graph）
- **流水线**：视频→30秒切分→中间输出（人脸检测、说话人分离）→记忆图（M3-Agent-Memorization 模型）

## 与本项目差异

| 维度 | M3-Agent | 本项目 (Week 3 MVP) |
|------|----------|---------------------|
| 输入 | 长视频 + 音频 | GUI Agent 识别结果（应用名、页面、元素、操作） |
| 记忆结构 | 多模态图（.pkl） | SQLite 结构化表 + 压缩摘要 |
| 清洗/压缩 | 模型端隐式 | 规则：合并相似、去歧义、去不合理 |
| 用户画像 | 无显式 | 应用频率、常用页面、行为模式 |
| 检索 | GPT-4o + 迭代推理 | 关键词 + 自然语言分词匹配 |

## 可借鉴点

1. **分层记忆**：原始识别 vs 压缩摘要，检索时优先摘要
2. **实体中心**：按应用、页面聚合，便于画像
3. **检索驱动**：为查询服务，存冗余便于多路径检索
